# 28-Day Fitness Analytics

A reproducible pandas and NumPy exploration of a 28-day synthetic activity
log. The report calculates step totals and averages, goal-hit days, sleep
summary, weekly breakdowns, protocol-grouped averages, and a descriptive
steps/bench-press correlation.

The data is invented for practice. Group averages and correlations do not show
that one habit causes another and are not health advice.

## Run

Requires Python 3.10 or newer.

```powershell
python -m pip install -r requirements.txt
python analyze_fitness.py
python -m unittest -v
```
